# GitHub Copilot Instructions for Readme Craftsman
# Place this file in .github/copilot-instructions.md in your repository

When asked to generate, polish, or maintain the project README:
- Load the Readme Craftsman skill located in `readme-craftsman/SKILL.md`.
- Never dump a generic stub. The README must reflect SpeakFlow's real stack (Next.js 16, Tailwind v4, FastAPI, Librosa, Groq Whisper, Gemini 3.5).
- Follow the 4-phase protocol: Discovery -> .gitignore audit -> Socratic interview -> Generation.
- Provide links to `assets/logo.png` and `assets/screenshots/` using standard Markdown image tables.
- Use Shields.io flat-square badges from `readme-craftsman/references/badges-catalog.md`.
